单摆周期 力学

$$T = 2\pi\sqrt{\dfrac{L}{g}},\quad \theta(t) = \theta_0\cos(\omega t),\quad \omega=\sqrt{g/L}$$
小角度近似下单摆周期仅与摆长 $L$ 与重力加速度 $g$ 有关,与摆球质量无关。调节 $L$ 与 $g$ 观察周期变化,画摆球轨迹。
● 摆球 · 摆长 L · T = 2π√(L/g) · θ₀ 为初始摆角

弹簧振子(简谐+阻尼) 力学

$$m\ddot{x} = -kx - b\dot{x},\quad \omega_d=\sqrt{\omega_0^2-(b/2m)^2}$$
弹簧振子在阻力 $F_b=-bv$ 下的衰减振动。调节 $b$ 观察欠阻尼/临界阻尼/过阻尼三种状态。
m=1, k=5 · 蓝:位移曲线 · 红:包络线 ±A·e^(-bt/2m)

欧姆定律 电磁学

$$U = IR,\quad P = UI = I^2R$$
电压 U = 电流 I × 电阻 R。滑块改变 R 与 U,实时看 I 与 P,绘制 I-V 关系直线。
实线:I-V 直线(斜率 1/R) · 当前工作点(红) · 功率 P = UI

斜抛运动 力学

$$x = v_0\cos\theta\cdot t,\quad y = v_0\sin\theta\cdot t - \tfrac{1}{2}gt^2$$
初速度 $v_0$ 与角度 $\theta$ 给定,画完整轨迹 + 实时小球。射程 $R=v_0^2\sin(2\theta)/g$,最高点 $H=v_0^2\sin^2\theta/(2g)$。
虚线:理论抛物线 · 实线:已走轨迹 · 红球:当前 · 灰:最高点

光的折射(斯涅尔定律) 光学

$$n_1\sin\theta_1 = n_2\sin\theta_2,\quad \theta_c = \arcsin(n_2/n_1)$$
光从介质 1 进入介质 2 时折射。调节入射角 $\theta_1$ 与 $n_1/n_2$ 观察折射角 $\theta_2$;当 $n_1>n_2$ 且 $\theta_1>\theta_c$ 时全反射。
↑ 法线 · 蓝色:入射 · 绿色:折射 · 紫色:反射 · 红色:全反射
