力的合成(平行四边形法则) 力学

$$\vec{F}_{\text{合}} = \vec{F}_1 + \vec{F}_2,\quad |\vec{F}_{\text{合}}| = \sqrt{F_1^2 + F_2^2 + 2F_1 F_2 \cos\theta}$$
两共点力的合力大小等于以两力为邻边的平行四边形对角线。拖动滑块改变两力夹角,观察合力矢量实时变化。
🔵 F₁ · 🟢 F₂ · 🔴 F合 · 灰虚线:平行四边形

简谐振动(SHM) 力学

$$x(t) = A\cos(\omega t + \varphi),\quad \omega = \sqrt{k/m},\quad T = 2\pi/\omega$$
弹簧振子在回复力 $F=-kx$ 下的位移时间曲线。点击"播放/暂停"观察振动,滑块改变振幅 A 与角频率 ω。
● 振子位置 · 曲线:位移-时间 · 中线为平衡位置

电场线(正/负电荷) 电磁学

$$\vec{E} = \frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}\hat{r},\quad \text{电力线:沿 }\vec{E}\text{ 方向}$$
点电荷的电场线分布:正电荷向外辐射,负电荷向内汇聚。点击 SVG 任意位置放置一个 +q(红)或 -q(蓝)试探电荷。
点击画布放置电荷 · 箭头方向为 $\vec{E}$ 方向

双缝干涉(杨氏实验) 光学

$$I = I_0\cos^2\!\left(\frac{\pi d\sin\theta}{\lambda}\right),\quad \Delta y = \frac{\lambda L}{d}$$
相干光经双缝后干涉,屏上出现明暗相间条纹。拖动滑块改变缝间距 d,条纹间距随之变化。
亮纹中心:$\Delta = d\sin\theta = k\lambda$ · 中央最亮

抛体运动(平抛) 力学

$$x = v_0 t,\quad y = \tfrac{1}{2}gt^2,\quad \text{轨迹}:y = \frac{g}{2v_0^2}x^2$$
水平抛出后,水平匀速 + 竖直自由落体的合成。改变初速度 v₀ 与重力 g,观察抛物线轨迹变化。
🔴 抛体 · 蓝虚线:水平分量 · 红虚线:竖直分量 · 灰曲线:完整轨迹
