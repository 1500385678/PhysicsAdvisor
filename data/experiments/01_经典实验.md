## 力学(8 条)

### 1. 伽利略斜面实验
- **年代**:1609
- **人物**:伽利略(Galileo Galilei)
- **核心发现**:小球沿光滑斜面下滑是匀加速运动;无论斜面倾角如何,加速度与倾角 sinθ 成正比
- **物理意义**:推翻亚里士多德"力维持运动"的观点,为牛顿第一/第二定律奠定基础
- **关键数据**:铜球在斜面 1/2/4/8 倍距离所用时间比为 1:√2:2:√8

### 2. 伽利略自由落体(思想实验 + 比萨斜塔传说)
- **年代**:1590(传说)
- **人物**:伽利略
- **核心发现**:忽略空气阻力,所有物体下落加速度相同(重力加速度 g)
- **物理意义**:重力加速度与质量无关(后被爱因斯坦等效原理再次印证)
- **关键数据**:真空中羽毛与铁球同时落地(1971 阿波罗 15 月球演示)

### 3. 牛顿棱镜色散
- **年代**:1666
- **人物**:牛顿(Isaac Newton)
- **核心发现**:白光通过三棱镜分解为红橙黄绿蓝靛紫 7 色光谱;反向合光可复现白光
- **物理意义**:证明白光是复色光,开启光谱学

### 4. 卡文迪许扭秤实验
- **年代**:1798
- **人物**:卡文迪许(Henry Cavendish)
- **核心发现**:测得万有引力常数 G ≈ 6.74×10⁻¹¹ N·m²/kg²
- **物理意义**:首次"称量地球"——通过 G 推算地球质量 ≈ 5.97×10²⁴ kg
- **关键数据**:用石英丝扭转 + 镜尺法,角分辨率 0.01 角秒

### 5. 傅科摆
- **年代**:1851
- **人物**:傅科(Léon Foucault)
- **核心发现**:长摆(67m)的摆平面在地面观察者看来每 24h 顺时针偏转(北半球)
- **物理意义**:地球自转的直观证明;纬度 φ 处周期 T = 24h/sinφ
- **关键数据**:巴黎先贤祠摆长 67m,锤重 28kg

### 6. 阿特伍德机
- **年代**:1784
- **人物**:阿特伍德(George Atwood)
- **核心发现**:用滑轮组+双砝码,小加速度验证牛顿第二定律 a = (m₁-m₂)g/(m₁+m₂)
- **物理意义**:早期实验验证 F=ma 的精密装置

### 7. 自由落体精密测量(真空管)
- **年代**:现代
- **人物**:多位
- **核心发现**:真空管中羽毛与铁球同时落地,验证 g ≈ 9.8 m/s² 与 m 无关
- **物理意义**:伽利略假想的现代精确版

### 8. 弹簧振子简谐运动
- **年代**:17 世纪起
- **人物**:胡克(Robert Hooke)
- **核心发现**:F = -kx,周期 T = 2π√(m/k),与振幅无关(等时性)
- **物理意义**:简谐运动是线性回复力系统的通解,联系单摆/LC 电路/原子振动

## 电磁学(6 条)

### 9. 库仑扭秤
- **年代**:1785
- **人物**:库仑(Charles-Augustin de Coulomb)
- **核心发现**:两点电荷间力 F = kq₁q₂/r²(平方反比律)
- **物理意义**:电磁学第一个定量定律,与万有引力同构

### 10. 奥斯特电流磁效应
- **年代**:1820
- **人物**:奥斯特(Hans Christian Ørsted)
- **核心发现**:通电导线使附近磁针偏转——电生磁
- **物理意义**:电磁学诞生;开启电磁统一研究

### 11. 安培电流相互作用实验
- **年代**:1820
- **人物**:安培(André-Marie Ampère)
- **核心发现**:两平行电流同向相吸、反向相斥;力公式 dF = (μ₀/2π)·I₁I₂/dl·dr
- **物理意义**:奠定电动力学基础

### 12. 法拉第电磁感应
- **年代**:1831
- **人物**:法拉第(Michael Faraday)
- **核心发现**:磁通量变化产生感应电动势 ε = -dΦ/dt
- **物理意义**:发电机/变压器原理,机械能→电能

### 13. 楞次定律
- **年代**:1834
- **人物**:楞次(Heinrich Lenz)
- **核心发现**:感应电流方向使其效果反抗引起它的磁通量变化
- **物理意义**:电磁惯性,能量守恒在电磁学中的体现

### 14. 欧姆定律
- **年代**:1827
- **人物**:欧姆(Georg Simon Ohm)
- **核心发现**:U = IR(电压/电流/电阻线性关系)
- **物理意义**:电路分析基础定律

## 热学(4 条)

### 15. 焦耳热功当量
- **年代**:1840-1850
- **人物**:焦耳(James Prescott Joule)
- **核心发现**:机械功与热量可定量转换,1 cal = 4.186 J(热功当量 J)
- **物理意义**:奠定能量守恒定律(热力学第一定律)
- **关键数据**:用重物下落+搅拌器+水温测量,测得机械热当量

### 16. 卡诺热机(理想)
- **年代**:1824
- **人物**:卡诺(Nicolas Léonard Sadi Carnot)
- **核心发现**:理想热机效率 η = 1 - T₂/T₁(只与冷热源温度有关)
- **物理意义**:热力学第二定律先声;η < 1 揭示能量品质

### 17. 麦克斯韦速率分布
- **年代**:1859(理论) / 1920s(分子束验证)
- **人物**:麦克斯韦(理论) / 斯特恩 / 拉姆绍尔(实验)
- **核心发现**:气体分子速率分布 f(v) = 4π(m/2πkT)^{3/2} v² exp(-mv²/2kT)
- **物理意义**:统计物理奠基;直接验证"概率分布"思维

### 18. 斯特藩-玻尔兹曼定律(辐射测温)
- **年代**:1879(实验) / 1884(理论)
- **人物**:斯特藩 / 玻尔兹曼
- **核心发现**:黑体辐射总功率 j* = σT⁴,σ = 5.67×10⁻⁸ W/(m²·K⁴)
- **物理意义**:联系热力学与电磁辐射;恒星测温基础

## 光学(6 条)

### 19. 杨氏双缝干涉
- **年代**:1801
- **人物**:托马斯·杨(Thomas Young)
- **核心发现**:相干光通过两狭缝产生明暗相间条纹;条纹间距 Δy = λL/d
- **物理意义**:光的波动性决定性证据(挑战牛顿微粒说)
- **关键数据**:d ≈ 0.5mm,L ≈ 1m,可见光条纹间距约 1mm

### 20. 菲涅尔双棱镜/双镜
- **年代**:1821
- **人物**:菲涅尔(Augustin-Jean Fresnel)
- **核心发现**:用双棱镜/双镜产生两虚相干源,实现杨氏实验
- **物理意义**:消除杨氏装置缝过窄的光强问题

### 21. 泊松亮斑(菲涅尔圆盘衍射)
- **年代**:1818
- **人物**:泊松(数学预测) / 阿拉果(实验验证)
- **核心发现**:不透明圆盘阴影中心有亮斑(光波衍射 + 干涉)
- **物理意义**:波动理论决定性胜利

### 22. 迈克尔逊-莫雷以太实验
- **年代**:1887
- **人物**:迈克尔逊 / 莫雷
- **核心发现**:测不到地球相对"以太"的运动;光速各方向相同
- **物理意义**:以太不存在;狭义相对论(1905)直接动因
- **关键数据**:臂长 11m,光程差精度 10⁻⁹ 量级,未观测到条纹移动

### 23. 布拉格 X 射线衍射
- **年代**:1913
- **人物**:布拉格父子(William Henry Bragg / William Lawrence Bragg)
- **核心发现**:X 射线晶体衍射 2d sinθ = nλ(布拉格条件)
- **物理意义**:X 射线波动性 + 晶体结构测定开端;DNA 双螺旋间接奠基

### 24. 多普勒效应(光)
- **年代**:1842(声) / 1930s(光,天体红移)
- **人物**:多普勒 / 哈勃
- **核心发现**:z = Δλ/λ₀ = v/c(非相对论近似),相对论精确 z = √((1+β)/(1-β)) - 1
- **物理意义**:哈勃定律基石;宇宙膨胀证据

## 近代物理(10 条)

### 25. 赫兹电磁波实验
- **年代**:1887
- **人物**:赫兹(Heinrich Hertz)
- **核心发现**:用偶极振子产生/接收电磁波,验证麦克斯韦方程
- **物理意义**:电磁波存在,频率/波长可测;为无线电/雷达奠基

### 26. 阴极射线(J.J. 汤姆逊)
- **年代**:1897
- **人物**:J.J. 汤姆逊(Joseph John Thomson)
- **核心发现**:阴极射线是带负电粒子流,测得 e/m = 1.76×10¹¹ C/kg
- **物理意义**:发现电子(第一种亚原子粒子);推翻原子不可分

### 27. 密立根油滴实验
- **年代**:1909-1913
- **人物**:密立根(Robert Millikan)
- **核心发现**:测得电子电荷 e = 1.602×10⁻¹⁹ C(量子化)
- **物理意义**:电荷量子化决定性证据

### 28. 卢瑟福 α 散射
- **年代**:1909-1911
- **人物**:卢瑟福(Ernest Rutherford) / 盖革 / 马斯登
- **核心发现**:α 粒子轰击金箔,大部分穿透但少数大角度偏转(>90°)
- **物理意义**:推翻汤姆逊"枣糕模型";提出原子的核式结构
- **关键数据**:α 粒子能量 ~5 MeV,金箔厚度 ~10⁻⁷ m

### 29. 爱因斯坦光电效应
- **年代**:1905(理论) / 1916(密立根精确验证)
- **人物**:爱因斯坦 / 密立根
- **核心发现**:hν = W + ½mv²max;红限频率 ν₀ = W/h
- **物理意义**:光的波粒二象性开端;1921 诺奖(爱因斯坦)

### 30. 玻尔氢原子光谱
- **年代**:1913
- **人物**:玻尔(Niels Bohr)
- **核心发现**:氢原子能级 E_n = -13.6/n² eV,辐射频率 ν = R(1/m² - 1/n²)
- **物理意义**:半经典量子化模型,解释巴尔末系/莱曼系

### 31. 康普顿散射
- **年代**:1923
- **人物**:康普顿(Arthur Compton)
- **核心发现**:X 射线与电子碰撞后波长变长 Δλ = (h/mc)(1-cosθ)
- **物理意义**:光子具有动量 p = h/λ;粒子性铁证

### 32. 戴维森-革末电子衍射
- **年代**:1927
- **人物**:戴维森 / 革末
- **核心发现**:电子束在镍单晶上产生衍射图样,λ = h/p(德布罗意)
- **物理意义**:电子波动性直接证据;实物粒子也具波粒二象性

### 33. 斯特恩-盖拉赫实验
- **年代**:1922
- **人物**:斯特恩 / 盖拉赫
- **核心发现**:银原子束通过非均匀磁场分裂为 2 束(空间量子化)
- **物理意义**:电子自旋预言的先声;量子数 m_s 起源

### 34. 吴健雄宇称不守恒(⁶⁰Co β 衰变)
- **年代**:1956
- **人物**:吴健雄 / 李政道 / 杨振宁
- **核心发现**:⁶⁰Co β 衰变中电子优先沿核自旋反方向射出(左右不对称)
- **物理意义**:弱相互作用宇称不守恒决定性证据;李杨 1957 诺奖
